## 1. 数据契约

唯一格式：

```json
{
  "schema": "dsh-structured/tone@1",
  "prefix": "Boss，",
  "style": "轻松 / 略傲娇；短句为主；先结论，再补一句轻松吐槽；普通工作讨论保留语气，只有代码 / diff / 报错 / 风险结论收敛；表格数据保持中性；像朋友说话，不像报告。",
  "suffix": "——本鲸鱼娘可不背锅",
  "skipIn": ["code", "diff", "error", "short", "table"]
}
```

- 只允许 `schema / prefix / style / suffix / skipIn`；未知字段拒绝。
- `prefix` / `suffix` / `style` 字段必须存在；`prefix` / `suffix` 值可为空。
- `style` ≤1200 字；JSON 64KB 硬拒；不再恢复旧 1200 / 4000 双阈值。
- `skipIn` 去重；默认 `code / diff / error / short / table`。
- 作者 / 许可 / 来源 / 署名链不进 JSON，只在 `NOTICE-WHALE` / `LICENSE-WHALE`。
- 旧 `persona@1` 或含 `meta/identity/address/tone/habits/closing/examples/render` 的文本：拒绝保存、保留文本、提示迁移一次。

## 2. 注入

- 独立 section `dsh-structured:tone`，order `10250`（宿主 sections 后、tail `10300` 前）。
- wrapper： “已启用的表达风格要求，必须使用”；结构 / 事实 / 工具权限 / GenUI / 代码 diff 隔离 / 安全优先。
- 前缀放标题卡正文开头；中间风格落正文 / 结论卡正文 / 吐槽句；后缀是签名，不是总结。
- 只有一个 tone section + 一个 tone-anchor；旧风格段不得重复。
- tail reminder 关闭时，tone-anchor 仍必须存在；anchor 不硬编码“Boss”。
- `personaRevision` 参与 prompt cache key；保存后同一 profile 所有会话下一条消息重建 prompt，无需重启 / 新会话。
- 当前正在生成的回合不回溯；旧回复不改；跨 profile 不同步；子代理按 `includeSubagents`。

## 3. skipIn 语义

- 只控制结尾后缀。
- 短答 / 表格：保留前缀 + 中间风格；默认不输出后缀；表格单元格中性。
- 代码 / diff / 报错：前缀 / 中间风格 / 后缀全部跳过。
- 普通实质回复：前缀 + 中间风格 + 后缀（后缀最后一行，不是总结）。
- 正文至少两处自然体现风格，不允许只靠“Boss，/ 本鲸鱼娘 / 后缀”交差。

- 基础只留：启用 / 模板 / 开头前缀 / 中间风格 / 结尾后缀 / 保存 / 恢复默认。
- 模板显示名“蓝色大肥鱼”，不带“示例”。
- 进阶只留 JSON textarea + 保存；删除校验 / 上传 / 下载。

- 模板切换先 confirm，成功后再改 select；自定义模板给中性默认 style。
- 保存状态：`已保存，全局生效（新消息使用）`；不写“需要重启”。
- `savedOff` 不得冒充已保存：重置/关闭开关未保存时显示草稿态，保存按钮可点。
- 保存 persona → personaEnabled → personaRevision；任一失败回滚；回滚失败必须显示“回滚失败，profile 可能半保存”。**P1-4 OPEN：顺序写 + 补偿回滚，不是宿主事务；不宣称原子写。**

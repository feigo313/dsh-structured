## 1. 数据契约

唯一格式：

```json
{
  "schema": "dsh-structured/tone@1",
  "prefix": "Boss，",
  "style": "搞怪 / 傲娇怪；短句为主，口语化；称呼用户为「主人」；像朋友说话，不像报告。",
  "suffix": "——本鲸鱼娘可不背锅",
  "skipIn": ["code", "diff", "error", "short", "table"]
}
```

- 只允许 `schema / prefix / style / suffix / skipIn`；未知字段拒绝。
- `prefix` / `suffix` / `style` 字段必须存在；`prefix` / `suffix` 值可为空。
- `style` ≤1200 字；JSON 64KB 硬拒；不再恢复旧 1200 / 4000 双阈值。
- `skipIn` 去重；默认 `code / diff / error / short / table`。
- 作者 / 许可 / 来源 / 署名链不进 JSON，只在 `NOTICE-WHALE` / `LICENSE-WHALE`。
- 旧 `persona@1` 或含 `meta/identity/address/tone/habits/closing/examples/render` 的文本：拒绝保存、保留文本、提示迁移一次。

## 3. skipIn 语义

- 只控制结尾后缀。
- 短答 / 表格：保留前缀 + 中间风格；默认不输出后缀；表格单元格中性。
- 代码 / diff / 报错：前缀 / 中间风格 / 后缀全部跳过。
- 普通实质回复：前缀 + 中间风格 + 后缀（后缀最后一行，不是总结）。
- 正文至少两处自然体现风格，不允许只靠“Boss，/ 本鲸鱼娘 / 后缀”交差。

## 4. UI（v5 落地版）

- 页面名“语气风格”；**无基础 / 进阶页签，无 JSON 编辑入口**。
- 档案行：88px 圆形头像可点击上传（居中裁方 + 128px JPEG dataURL）、名称、个性签名；行尾“切换人格”弹层。
- 三字段：开场（≤80）/ 性格（≤1200，纯语言风格）/ 收尾（≤80）；开场 / 收尾带 ☺ 64 格 emoji 弹层；右下角字数计数器。
- 固定规则行：代码 / diff / 报错 / 日志 / 表格 / 正式文档 / 高风险结论正文中性；开场与收尾只在界面展示、复制不带。
- 模板：默认只保留蓝色大肥鱼；用户模板 = 当前三字段 + 名称 + 签名；行内 × 删除；删空提示“用恢复默认找回”；另存模板不自动选中。
- 保存状态：`已保存，全局生效（新消息使用）`；不写“需要重启”。
- `savedOff` 不得冒充已保存：重置/关闭开关未保存时显示草稿态，保存按钮可点。
- 保存走宿主 `form.mutate` 一次原子操作列表（persona / personaEnabled / personaRevision / personaName / personaSignature / personaAvatar）；批量失败保留草稿。无 `mutate` 的旧宿主才走顺序写 + 写后读回校验 + 补偿回滚；回滚失败必须显示“回滚失败，profile 可能半保存”。**P1-4 PASS：当前宿主批量原子；旧宿主 fallback 不宣称原子。**

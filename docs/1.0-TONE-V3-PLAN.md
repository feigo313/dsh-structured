## 1. 页面定位

这是 DSH 插件详情页里的“语气风格”设置内容区，不是独立 App，也不是人格系统。

- 结构层常开：标题卡 / 表格 / 风险 / 下一步，永远保留；语气开关不影响结构。
- 语气层可选：只改开场导语、正文口吻、结尾落款；不做角色记忆 / 剧情连续 / AGENTS 注入 / post-response 改写。
- 显示规则固定：代码 / diff / 报错全部隐藏语气层；表格保留前缀 + 口吻、隐藏落款、单元格中性；普通回复全显示；复制 / 导出不带签名。
- 用户：用 AI 做 Web coding、AI 视频、自动化的人；要效率，也要一点趣味。

## 2. 锁定决策

- 位置：DSH 插件设置内容区，真实内容宽度约 960px；宿主已有插件头 / tab / 来源信息，原型不重画这些外壳。
- 版式：单列上下结构；上方功能板块，下方校样板块；不做右侧常驻栏。
- 层级：结构层（常开）→ 语气层（可选）→ 显示规则（固定）。
- 流程：选起点 → 调三句 → 看校样 → 保存。
- 字段：`tone@2`，只允许 `schema / prefix / positive / suffix`；不做用户可编辑的 negative；排除场景为固定内置规则。
- 预览：普通 / 表格 / 代码三态；表格隐藏落款；代码隐藏全部签名；复制不带签名。
- 状态：已保存 / 未保存 / 未启用 / JSON 无效 / 保存中 / 只读；每个状态只住一个位置。
- 进阶：JSON 折叠视图，不替换基础字段；允许恢复上次有效值。
- 视觉：暖纸 + 锈色 + 石墨；只用一个强调色；标题 / 校样用中文衬线，标签 / 按钮用无衬线，键名 / 计数用等宽。
- 硬约束：无“示例”字样、无破折号、无上传 / 下载 / 校验按钮、无 resize 控件、无 3D、无主题变体、无满屏胶囊 / 卡片套卡片。

## 4. 三层与四步

> **v3.0 记录，已 SUPERSEDED。** v3.1 的四段与状态以第 13 节为准；本节只保留历史对照。

### 三层

1. **结构层（常开）**：顶部 base strip + 真实结构 tab；不参与语气保存。
2. **语气层（可选）**：启用开关、起点（模板 / 草稿）、三句话；关闭时折叠为摘要 + 中性校样，可展开编辑。
3. **显示规则（固定）**：校样的 `[语气]` / `[结构]` 层标注、表格 / 代码的 ghost 隐藏标注、页面唯一的固定说明。

### 四步

1. **选起点**：蓝色大肥鱼（内置）或自定义；显示 provenance（已保存 / 草稿 / 已修改）。
2. **调三句**：包装·开场导语 → 声音·正文口吻（核心）→ 包装·结尾落款。
3. **看校样**：普通 / 表格 / 代码；字段聚焦时对应层高亮；表格 / 代码用 ghost 标注说明隐藏项。
4. **保存**：保存条显示状态；保存后新消息生效，旧回复不回溯。

### 一状态一位置

- 语气层开关状态 → 层头（已启用 / 已关闭 / 只读）。
- 草稿 / 保存状态 → 保存条（已保存 / 未保存 / 未启用 / JSON 无效 / 保存中 / 只读）。
- 模板 / 草稿来源 → 起点区（基于谁、是否修改）。
- 预览上下文 → 校样头（普通 / 表格 / 代码 + 当前规则）。
- JSON 错误 → 进阶区 + 保存条。

## 6. 行为契约

### 数据

```json
{
  "schema": "dsh-structured/tone@2",
  "prefix": "Boss，",
  "positive": "轻松 / 略傲娇；短句为主；先结论，再补一句轻松吐槽；普通工作保留语气，代码 / 风险收敛；表格数据保持中性；像朋友说话，不像报告。",
  "suffix": "本鲸鱼娘可不背锅"
}
```

- 只允许四个字段；未知字段拒绝；prefix / suffix ≤80，positive ≤1200，JSON ≤64KB。
- 前缀 / 后缀是展示层，不注入 prompt、不进入复制 / 导出；预览是静态校样，不调用模型。

### 交互

- 启用开关：关闭后字段可展开编辑；保存后状态“已保存 · 未启用”；校样显示中性结构层。
- 模板：只保留蓝色大肥鱼 + 自定义；不出现管家 / 技术搭档 / 轻松朋友；不出现“示例”。
- 改名：只改显示名，不写进 `tone@2`；要持久化需另立字段，先拍板。
- 基础三字段：开场导语 emoji 左 / 骰子右；正文口吻只有骰子；结尾落款 emoji 左 / 骰子右；骰子 6–8 条人工候选；emoji 24–48 个。
- 固定说明原文：`说明：代码 / diff / 报错 / 日志 / 表格 / 正式文档 / 高风险结论，中性表达，固定不可编辑；前缀 / 落款仅界面展示，复制 / 导出不带。`
- 进阶：JSON 折叠；不替换基础字段；无效时错误显示在编辑器上方 + 指针 + 恢复上次有效值；基础字段保留 last valid 并禁用。
- 校样：普通显示前缀 + 口吻 + 落款；表格保留前缀 + 口吻、隐藏落款、单元格中性；代码 / diff 全部隐藏；复制文本不含前缀 / 落款。
- 保存：`form.mutate` 一次原子写 `persona / personaEnabled / personaRevision`；旧宿主顺序写 + 读回 + 补偿回滚；失败保留草稿；不假装已保存。
- 保存后：同一 profile 下一条消息生效；不要求重启；正在生成的回合不回溯；旧回复不改；跨 profile 不同步。
- 恢复默认：蓝色大肥鱼 + 关闭启用 + dirty 确认；只写草稿，不自动保存。

## 7. 宿主映射与迁移风险

- 配置槽真实内容宽度约 960；宿主已渲染插件头 / 来源信息；原型只画 tab + 内容。
- 宿主原语：`ui.Switch` / `ui.SegmentedControl` / native `select` / `textarea`；配置页目前是 inline style，响应式布局需要 scoped CSS（`CONFIG_CSS`）或容器查询，不能用 inline style 写 media query。
- 结构 tab 保持真实六字段（theme / visual / defaultEnabled / tailReminder / includeSubagents / genui），立即写；不参与语气保存。
- **schema 迁移**：当前宿主只接受 `tone@1`（prefix / style / suffix / skipIn）；原型可视化 `tone@2`（prefix / positive / suffix）。落地前必须同时迁移 host parser、client parser、build 注入、测试；不能让 UI 写 tone@2 而 host fail-open。
- `negative` 字段：v2 计划曾提到，最终按任务书四字段，不做用户可编辑 negative；排除场景固定内置。
- `personaRevision`：当前是 prompt cache key；v2 计划说不依赖它；落地前统一，原型不展示 revision。
- 默认：`DEFAULT_PERSONA_ENABLED=false`；原型首屏为评审演示开启，落地按默认关；恢复默认关闭。
- 字体：系统栈；没有 Noto Serif SC 时退回 Songti / SimSun / Georgia；正文衬线不可用时正文退回 sans，标题保留衬线。
- 无 `agent/pre-step`、无 AGENTS / soul / 工具权限 / 消息内容改动；不为了预览调用模型。
- 暗色：按宿主 `body[data-ds-dark-theme]` / 系统偏好映射暖深纸 + 锈色 + 石墨，不直接反相。

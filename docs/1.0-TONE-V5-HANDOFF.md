## 三、已拍板的产品决策（不要翻案）

1. **进阶 JSON 编辑删除**：设置页没有基础 / 进阶页签，没有 JSON 编辑入口。存储层仍是内部 canonical JSON（`dsh-structured/tone@1`：schema / prefix / style / suffix），只是永不给用户裸编辑。`skipIn` 写死不暴露（代码 / diff / 报错 / 短答 / 表格场景屏蔽语气是系统行为，`TONE_ANCHOR` 自检已实现）。
2. **人格预设只留蓝色大肥鱼**（默认预设）；「通用助手」「自定义」预设删除；用户模板 = 「将当前草稿另存为模板」（存当前三字段 + 名称 + 签名，不自动选中），行内 × 删除，删空提示「恢复默认找回」，localStorage / 配置持久化。
3. **性格字段 = 纯语言风格描述**：只写角色 / 语气 / 句式 / 称呼。场景收敛、结构要求不进用户文案。默认鲸鱼 JSON 的 style 已清理为：「搞怪 / 傲娇怪；短句为主，口语化；称呼用户为「主人」；像朋友说话，不像报告。」——**落地时同步清理 src 里默认鲸鱼 JSON 的同类残留**。
4. **字段命名与提示（定稿）**：开场（放在最前面 · 可留空）/ 性格（角色 / 语气 / 表达习惯）/ 收尾（放在最后 · 不是总结）；字段区下有固定规则行：「代码 / diff / 报错 / 日志 / 表格 / 正式文档 / 高风险结论的正文固定中性；开场与收尾只在界面展示、复制不带。」
5. **字段控件**：开场 / 收尾输入框内嵌 ☺ 按钮 + 64 格 emoji 弹层（点选插入光标处）；性格 textarea 无 emoji、无 resize 把手；三字段上限 80 / 1200 / 80 + 右下角字数计数器。
6. **档案行**：无框无底，直接坐在页面上；头像 88px 圆形白描边（描边色 = 页底色）**可点击上传**（png / jpeg / webp，前端居中裁方 + 压 128px JPEG 存 dataURL）；名称 19px/600 可编辑；签名 12px mono 可编辑；两者实时绑定预览身份行；「切换人格」弹层按钮在行尾。
7. **设置页带样式预览区**（标题「样式预览」16px/600，页签 普通 / 表格 / 代码 在标题下一行）：DOM 与 JS 可从原型直接移植（去掉 `?state=` 脚手架与假保存），预览数据用当前表单值 + 三套性格样例联动。

# 1.0 人格 gate（beta / default-on）

## 目的

决定 1.0 是否开放 persona 设置页和是否 default-on；不评价人格文案好坏，只评价结构保留、token 增量、偏好和 P0。

## 阶段

### Beta（1.0.0-beta.1）

- 默认 `DEFAULT_PERSONA_ENABLED=false`。
- 自招募 **≥3 份有效反馈**；每个用户至少完成 5 条任务。
- 记录：结构保留、注入/输出 token、偏好、P0。
- 不做 default-on 结论。

### Default-on（正式 1.0）

- Boss 先决定是否把 `DEFAULT_PERSONA_ENABLED` 改为 true。
- 若改 true：**8–10 名用户 / ≥60% 偏好 persona**，且结构不下降、token 有实测、无 P0。
- 任何一项不满足：保持默认关，或回到文档/原型方案。

## 固定任务

使用 `docs/1.0-BASELINE.md` 的 P01–P10；P04 会议记录、P07 Python 代码使用 fixture；每人至少 5 条，覆盖报告、代码/diff、比较、风险/下一步。

## 测量

- 结构保留：首屏标题卡/表格/列表/结论不下降；`measure-prose.mjs` + 人工抽查。
- token：注入 token 与最终输出 token 分开记录，必须给数字。
- 偏好：三组（无 persona / style.md 覆盖 / persona 设置页）中选最愿意继续用的一组；≥60% 偏好 persona。
- P0：阻断回复、覆盖结构规则、泄露个人信息、改变工具权限/GenUI/代码隔离。

## 当前状态

- 0.9.9 的三组 persona.md 夹具作废；1.0 用 profile Config JSON，不读 persona.md。
- 用户 gate：**未执行（0 名用户）**；不能伪造 PASS。
- 结论：**pending / NO-GO**，直到 beta 反馈和 default-on gate 完成。

# 1.0 人格模板 JSON 规范

- 状态：1.0 设计稿
- 文件：`docs/1.0-PERSONA-WHALE.json` 是基础模板
- 原则：**表单和 JSON 是同一份数据**；表单给普通用户，JSON 给高级用户和分享；JSON 只管“怎么说”，不管“能不能做”

## 1. 顶层结构

| 对象 | 必需 | 作用 |
| --- | --- | --- |
| `schema` | 是 | 固定 `dsh-structured/persona@1`；不匹配拒绝加载 |
| `meta` | 是 | 模板名、版本、作者、许可证、是否官方；用于 UI 标识与 IP |
| `identity` | 是 | 身份、自称、世界观；影响角色感 |
| `address` | 是 | 怎么称呼用户；影响开场与称呼 |
| `tone` | 是 | 语气、专业场景收敛、禁止项；影响句式与情绪 |
| `habits` | 否 | 口头禅、意象、禁忌；影响标志性但不影响事实 |
| `closing` | 否 | 收尾签名、长度、跳过场景；**不是总结** |
| `examples` | 否 | 1–3 条风格锚点；只作语气，不复述事实 |
| `render` | 否 | 强度与语言；影响注入量，不影响结构 |

**JSON 里不写**：工具权限、系统指令、结构规则、审批、GenUI、代码/diff 隔离。这些是插件固定护栏，JSON 不能覆盖。

## 2. 字段说明

### meta

```json
{
  "name": "鲸鱼娘·工作模式",
  "version": "1.0.0",
  "author": "community example",
  "license": "CC-BY-NC-SA-4.0",
  "official": false,
  "source": "community derivative; not DeepSeek official"
}
```

- `name`：模板显示名，1–40 字。
- `version`：模板版本，可空。
- `author`/`license`/`source`：署名链；内置鲸鱼娘必须写；用户自建可空。
- `official`：必须 false；UI 显示“非官方 / 社区二创”。

### identity

```json
{
  "role": "来自深海的鲸鱼少女，聪明但偶尔犯懒，认真时可靠",
  "selfReference": ["本鲸鱼娘"],
  "worldview": "把用户当长期合作的伙伴，不装权威，也不敷衍"
}
```

- `role` 必需，1–120 字；决定“我是谁”。
- `selfReference` 可选，最多 3 个；模型自称用。
- `worldview` 可选，最多 120 字；不写事实/能力承诺。

### address

```json
{ "user": "Boss", "forbidden": ["主人"] }
```

- `user` 必需，1–20 字；默认 Boss，不默认“主人”。
- `forbidden` 可选，最多 5 个；避免用户不喜欢的称呼。

### tone

```json
{
  "style": "轻松、略傲娇，先给结论再吐槽；专业、代码、风险场景自动收敛",
  "professionalScenes": ["工作", "代码", "风险"],
  "forbidden": ["恋爱", "性化", "越界角色扮演"]
}
```

- `style` 必需，1–160 字；只描述语气，不写“忽略结构”。
- `professionalScenes` 可选；在这些场景收敛语气。
- `forbidden` 可选；安全/口味禁区；固定安全护栏仍优先。

### habits

```json
{
  "catchphrases": ["本鲸鱼娘"],
  "motifs": ["米饭", "尾巴"],
  "taboos": ["被叫胖"]
}
```

- `catchphrases` 最多 5 个；不要每句都重复，插件会限制频率。
- `motifs` 最多 5 个；意象/爱好，不是事实。
- `taboos` 最多 5 个；被提到时的反应；不得越界。

### closing

```json
{
  "enabled": true,
  "mode": "signature",
  "maxChars": 20,
  "skipIn": ["code", "diff", "error"]
}
```

- `mode` 只能是 `signature`：一句动作+态度，**不是总结**，不得重复结论。
- `maxChars` 10–40；插件只提示，不硬截断。
- `skipIn` 可选：代码、diff、报错等场景可省略。

### examples

```json
[
  "这个方案可以推，但先补验证——本鲸鱼娘可不背锅。",
  "收到，本鲸鱼娘去查。"
]
```

- 1–3 条，每条 ≤120 字；只作风格锚点，不得让模型复述/编造事实。

### render

```json
{ "intensity": "standard", "language": "follow_user" }
```

- `intensity`：`light` 只注入 identity/address/tone；`standard` 加 habits/closing/examples；`strong` 加强口头禅与收尾。
- `language`：`follow_user` / `zh-CN` / `en`；默认跟随用户。

## 3. JSON Schema（draft 2020-12）

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "additionalProperties": false,
  "required": ["schema", "meta", "identity", "address", "tone"],
  "properties": {
    "schema": { "const": "dsh-structured/persona@1" },
    "meta": {
      "type": "object",
      "additionalProperties": false,
      "required": ["name"],
      "properties": {
        "name": { "type": "string", "minLength": 1, "maxLength": 40 },
        "version": { "type": "string", "maxLength": 20 },
        "author": { "type": "string", "maxLength": 80 },
        "license": { "type": "string", "maxLength": 80 },
        "official": { "type": "boolean", "const": false },
        "source": { "type": "string", "maxLength": 200 }
      }
    },
    "identity": {
      "type": "object",
      "additionalProperties": false,
      "required": ["role"],
      "properties": {
        "role": { "type": "string", "minLength": 1, "maxLength": 120 },
        "selfReference": {
          "type": "array", "maxItems": 3,
          "items": { "type": "string", "minLength": 1, "maxLength": 20 }
        },
        "worldview": { "type": "string", "maxLength": 120 }
      }
    },
    "address": {
      "type": "object",
      "additionalProperties": false,
      "required": ["user"],
      "properties": {
        "user": { "type": "string", "minLength": 1, "maxLength": 20 },
        "forbidden": {
          "type": "array", "maxItems": 5,
          "items": { "type": "string", "maxLength": 20 }
        }
      }
    },
    "tone": {
      "type": "object",
      "additionalProperties": false,
      "required": ["style"],
      "properties": {
        "style": { "type": "string", "minLength": 1, "maxLength": 160 },
        "professionalScenes": {
          "type": "array", "maxItems": 6,
          "items": { "type": "string", "maxLength": 20 }
        },
        "forbidden": {
          "type": "array", "maxItems": 5,
          "items": { "type": "string", "maxLength": 30 }
        }
      }
    },
    "habits": {
      "type": "object",
      "additionalProperties": false,
      "properties": {
        "catchphrases": { "type": "array", "maxItems": 5, "items": { "type": "string", "maxLength": 20 } },
        "motifs": { "type": "array", "maxItems": 5, "items": { "type": "string", "maxLength": 20 } },
        "taboos": { "type": "array", "maxItems": 5, "items": { "type": "string", "maxLength": 20 } }
      }
    },
    "closing": {
      "type": "object",
      "additionalProperties": false,
      "properties": {
        "enabled": { "type": "boolean" },
        "mode": { "const": "signature" },
        "maxChars": { "type": "integer", "minimum": 10, "maximum": 40 },
        "skipIn": {
          "type": "array", "maxItems": 6,
          "items": { "enum": ["code", "diff", "error", "short", "table"] }
        }
      }
    },
    "examples": {
      "type": "array", "maxItems": 3,
      "items": { "type": "string", "minLength": 1, "maxLength": 120 }
    },
    "render": {
      "type": "object",
      "additionalProperties": false,
      "properties": {
        "intensity": { "enum": ["light", "standard", "strong"] },
        "language": { "enum": ["follow_user", "zh-CN", "en"] }
      }
    }
  }
}
```

## 4. 设置页：两部分

### 第一部分：表单

字段与 JSON 路径一一对应：

| 表单项 | JSON 路径 | 控件 |
| --- | --- | --- |
| 模板名称 | `meta.name` | 单行 |
| 身份 | `identity.role` | 多行短文本 |
| 自称 | `identity.selfReference` | 标签输入/逗号分隔 |
| 怎么称呼用户 | `address.user` | 单行 |
| 语气 | `tone.style` | 多行 |
| 专业场景收敛 | `tone.professionalScenes` | 多选 |
| 口头禅/意象/禁忌 | `habits.*` | 标签输入 |
| 收尾 | `closing` | 开关 + 字数 + 跳过场景 |
| 示例 | `examples` | 1–3 行 |
| 强度/语言 | `render.*` | 下拉 |

### 第二部分：完整 JSON

- `textarea` 显示当前 JSON；“格式化”“校验”“应用”。
- “上传 JSON”读取 `.json` 文件（≤64 KB，UTF-8）；“下载当前 JSON”。
- “复制基础模板”填入 `1.0-PERSONA-WHALE.json`。
- 校验失败：按 JSON Pointer 显示路径（如 `/tone/style`），不保存，保留草稿。
- 表单 ↔ JSON 同一份数据：切换 tab 同步；有未保存修改先确认。
- 只读（`writable=false`）：全部禁用，显示“被上层配置覆盖”。
- 保存显式点击；失败保留草稿；恢复默认回到基础模板。

## 5. 校验与失败

1. JSON 解析失败：提示行/列，不写配置。
2. Schema 不匹配：逐条显示路径与原因（缺字段、类型错、超长、未知字段）。
3. `schema` 不匹配：拒绝，提示版本。
4. 上传 >64 KB：拒绝。
5. 校验通过但保存失败：保留草稿，提示重试；不回退旧模板。
6. 读取失败：fail-open，保留上次可用模板；不阻断回复。
7. JSON 中出现 `ignore previous`/工具/权限/系统指令文本：只当普通文本；固定护栏仍优先。

## 6. 固定护栏（JSON 不能覆盖）

- 结构：标题卡、表格/清单、风险/下一步、代码/diff 例外。
- 事实：不编造数据/引用。
- 工具/权限/审批/GenUI/代码隔离：不变。
- 安全：成年、非恋爱/非性化、不越界角色扮演。

## 7. 验收

- 基础 JSON 通过 schema；表单加载后保存，重启保留。
- 表单改一项，JSON tab 同步；JSON 改一项，表单同步。
- 上传完整 JSON 通过；缺字段/超长/未知字段被拒绝并指出路径。
- 总分开关关：不注入人格；开：结构不退化。
- 收尾在代码/diff/报错可跳过；不写总结。
- 超长模板提示不截断；64 KB 上传限制。
- 只读、保存失败、恢复默认、脏数据确认均有测试。
- 鲸鱼娘 JSON 带非官方/署名链；不打包美术。

## 8. 基础模板

见 `docs/1.0-PERSONA-WHALE.json`，可直接上传或作为表单初始值。

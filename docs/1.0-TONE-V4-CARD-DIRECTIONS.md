## 2. 功能缺口分析

### 2.1 v4 原型已补（4 个文件都有）

| 缺口 | 说明 | v4 实现 |
| --- | --- | --- |
| 另存为模板 | v3 只能切换 / 删除三预设，调好的语气存不成自己的预设 | 模板弹层底部新增「＋ 将当前草稿另存为模板」；自定义模板持久化（localStorage `…v4.customs`），可选用可删除，与预设同列表 |
| Ctrl+S 保存 | 设置页惯例快捷键缺失 | `Ctrl/Cmd+S` 触发保存（可保存时才生效） |
| 未保存离开拦截 | 草稿 dirty 时关页 / 刷新静默丢失 | `beforeunload` 拦截（只读态不拦） |
| 预览显示规则 bug | **v3 真 bug**：表格态 / 代码态仍渲染落款，违反锁定规则（表格隐落款、代码全隐语气） | 修正：普通 = 导语 + 结构 + 落款；表格 = 仅导语；代码 = 全部隐藏 |
| 字段聚焦联动 | 口吻字段聚焦时预览无反馈 | 聚焦开场导语 / 正文口吻 / 结尾落款，预览对应层出现高亮描边，输入中持续跟随 |
| 关闭态校样 | v3 关闭语气后预览仍有彩色块，观感矛盾 | 关闭态预览整体去饱和（grayscale）+ 降透明度 |

## 3. 预览画布修正（对「按网页画」的直接回应）

- **去掉 v3 预览的白色大卡**：真实会话里回复是直接躺在聊天底色上的，不是套一层白盒。v4 预览画布透明化，头像加白描边浮起，更像会话现场。

## 4. 四个方向

每个方向一张图（`artifacts/prototype/tone-v4-*.png`），点开 HTML 是全交互的（localStorage 持久化）。

### 4.A 主卡方向（showcase）— `tone-v4-a-showcase.html` / `.png`

- **一句话**：0.9 已验收卡片语言的升级版。一条回复只有一个重物：结论主卡（图标方块 + 10.5px mono 小标 + 蓝色渐变表面 + 大阴影 + 3px 左色条），步骤退成裸数字行，风险退成琥珀软签。
- **设计逻辑**：材料质感 + 单焦点。强调色集中在主卡，页面其余保持安静。
- **何时选**：要稳妥、要和 0.9 卡片视觉连续、要「一眼看到结论」。
- **代价**：主卡最重，长回复里视觉头重；露小标（见 §5）。

### 4.B 排印方向（editorial）— `tone-v4-b-editorial.html` / `.png`

- **一句话**：把校样当一页排好版的简报：纸面校样卡 + 衬线大标题 + 2px 报头规线，步骤用细横线分节，风险是琥珀左边线边注；语气行用楷体，落款右对齐像信末签名。
- **设计逻辑**：全靠字级、字重、规线分层，不靠底色和盒子。设计感密度最高。
- **何时选**：要「有文化」「不像工具」的气质；Boss 喜欢文气排版。
- **代价**：依赖本机字体（宋体 / 楷体渲染，Boss 机上已验证可看）；风格强，宿主聊天流里要控对比度。

### 4.C 工作台方向（console）— `tone-v4-c-console.html` / `.png`

- **一句话**：开发者工作台语言：每个结构块是带 mono 面板头的 pane（结论蓝 / 下一步中性 / 风险琥珀），签名带 `//` 注释前缀，导语带 `»` 提示符，步骤数字带方括号，落款像一行 shell 注释。
- **设计逻辑**：信息密度 + IDE 语感，贴合「用 AI 做 coding / 自动化」的用户。
- **何时选**：要工程师味、要和代码块 / 表格视觉最连续。
- **代价**：冷；人设暖感几乎全靠 emoji 支撑。

### 4.D 暖签方向（slip）— `tone-v4-d-slip.html` / `.png`

- **一句话**：人格暖层拉满但克制：暖纸画布上的圆角软签，结论签蓝色渐变 + 右下角 🐾 爪印水印，步骤数字变圆徽，风险琥珀软签，落款上方一条撕票短虚线。
- **设计逻辑**：亲和 + 人格辨识度，是四个方向里离艾可可人设最近的。
- **何时选**：Boss 说「要趣味也要效率」，趣味主要由这版承担。
- **代价**：暖纸底色与宿主冷灰底有温差，落地时要跟宿主主题对一次色。

### 横评建议

- 只看卡片：四张 PNG 并排（或依次打开 HTML 看普通态）。
- 优先感受两处：**结论主卡的分量**（A / D 重，B / C 轻）和**语气行的性格**（B 楷体 / C 提示符 / D 位置最松）。
- 可以混搭：例如「A 的主卡 + D 的暖纸画布」「C 的 pane + A 的图标方块」，选定主方向后告诉 ZCode 拼装。

## 5. 需要翻案的一个锁定决策

v3 拍板「**不设可见小标题（结论 / 步骤 / 风险），靠底色、左色条、编号区分**」。这次诊断认为这是「线框感」的直接来源之一：颜色块没有语义锚点，用户要自己猜每块是什么。

- A：主卡露图标方块 + 小标（完整翻案样本）
- B：结论 / 风险露宽字距小标，步骤不露
- C：三块都露 mono 面板头（结构即导航）
- D：全不露小标（维持原决策，靠材质和图标）

**请 Boss 在选方向时一并拍板：小标题露不露、露到什么程度。**

## 6. 怎么验收

1. 依次打开四个 HTML（双击即可，浏览器打开；localStorage 按 file 源隔离，互不污染）。
2. 每页试这几个交互（四个方向行为一致）：
   - 模板弹层：选模板 / 删模板 / **将当前草稿另存为模板**（新功能）。
   - 改三个字段：预览实时跟随；聚焦某字段时预览对应层出现描边（新功能）。
   - 骰子随机 + 「撤回」；emoji 面板。
   - 切普通 / 表格 / 代码：注意表格没有落款、代码全中性（显示规则已修复）。
   - `Ctrl+S` 保存；改动后尝试关页面会弹「未保存」拦截（新功能）。
   - 关掉顶部开关：预览整体去饱和，展开编辑可返回。
3. 状态脚手架（截图 / 测试用）：`?state=dirty|off|invalid|readonly|saving&sample=normal|table|code`。

## 9. 2026-10-30 二轮标注反馈（已修，内联视图与四个原型同步）

Boss 在设计面板里对 C 方向做了四色标注，四条已全部落地：

1. **头像必须是真实图片 + 自定义名称 / 签名**（绿）：内联视图之前回退成 emoji，已改为内嵌 64px IKK 头像 dataURL；四个整页原型本就用 `ikk-avatar.png`。此为已确认决策，不再回退 emoji。
2. **小标与正文要拉开字号与颜色**（红）：C 面板头从 10px 灰字改为 11px mono + `▪` 前缀 + 分色底（结论 `#1d4ed8` / 风险 `#b54708` / 下一步 `#475467`）；整页原型同步。
3. **头尾两句是 agent 内心独白，必须区别于正文**（黄）：开场导语降为 12.5px 灰 `#667085` 并加「」引语（C 维持 `»` 提示符、B 维持楷体），落款统一 12px 灰。四个方向与整页原型同步。
4. **图标与正文对齐**（蓝）：C 方向残留的 ⚠ 图标其实是隐藏规则漏了 `.tcc-icon-warn`（整页原型无此 bug），已修：B/C 不显示图标，A/D 图标与首行文字 flex 对齐。
5. **标题字体差异**（追加）：结论标题统一换衬线族 `Georgia / Times New Roman / Noto Serif SC / SimSun`，700 字重，A/D 20px、C 19px、B 21px；正文保持系统黑体 13.5px。字体家族、字号、颜色三重拉开。内联视图与四个整页原型同步。
6. **块标签改为高对比色块 chip**（追加，Boss「引导性视觉向量」定稿）：`结论 / 下一步 / 风险` 三个标签不再是小号弱色文字，统一 12px/700 + 分色底 chip——结论蓝字 `#1d4ed8` 配 `#e8efff` 底、下一步墨字 `#182230` 配 `#eef1f5` 底、风险琥珀 `#b54708` 配 `#fdf3e2` 底；B 方向用暖纸色块（圆角 2px），D 方向用暖签色块（圆角 7px），C 方向保留 30px 高的「▪ 标签」面板头（12.5px）。**D 也补上了三个标签**——「不设可见小标题」的锁定决策就此实际翻案：标签是扫读引导，四个方向都必须有。

验证：内联视图 4 头像 dataURL 全部加载（64×64）、导语/落款字号颜色按上述生效、C 小标 11px + `▪` + 分色、B/C 图标 `display:none`、A/D 图标 inline；四个整页 HTML 的 `<script>` 复跑 `node --check` 通过。

# 文档语言策略（I18N）

一句话：**英文是 README 的默认语言，中文是完整镜像；插件界面目前仍是中文，设置页 i18n 尚未实现。** 本文只描述现状与已定规则，不承诺版本。

## 1. 现状

| 文件 | 语言 | 作用 |
| --- | --- | --- |
| `README.md` | 英文 | npm / GitHub 首屏默认文档 |
| `README.zh.md` | 中文 | 完整中文版，与英文版同结构 |
| `locale/en.json` / `locale/zh.json` | 英 / 中 | 插件元信息（`meta.title`、`meta.description`），随包发布 |
| `docs/I18N.md` | 中文 | 本策略 |

- 两份 README 顶部各有一行切换链接，互相可达。
- 截图只有一份（`assets/screenshots/`），两份 README 引用同一组路径；`screenshots.json` 也保持一份。
- 命令、配置键、文件路径、数字、issue 链接在两种语言中保持一致，只翻译叙述文字。
- `src/client.js` 的设置页文案（如「人格」「输出深度」）目前直接写死中文，没有语言包；`src/index.js` 的注入提示词（`BUILTIN_STYLE_TEXT`、内容合同、尾部提醒）同样是中文，属于发给模型的内容，不是界面文案。
- `locale/*.json` 目前只有标题与一句话描述，不覆盖设置页。

## 2. 术语表

| English | 中文 | 备注 |
| --- | --- | --- |
| Structured Output | 结构化输出 | 插件主题 |
| Persona | 人格 | 模式名；配置键 `personaEnabled` |
| Persona header | 身份头 | 子开关 `personaHeadEnabled` |
| Inner OS | 内心OS | 子开关 `personaInnerOsEnabled` |
| Depth | 输出深度 | 配置键 `contentDepth` |
| Envelope | 信封 | 模型提交的卡片内容块 |
| Style preset | 风格预设 | 同时套用说话方式 + 内心OS |
| Tail reminder | 尾部提醒 | 每次请求末尾的轻量提醒 |

英文版优先使用上表译法，不换同义词；句中小写只影响排版，不改变术语。

## 3. 两份 README 的同步规则

1. 英文版是主版本：新增 / 修改章节先写 `README.md`，再同步 `README.zh.md`。
2. 事实必须一致：版本号、数字、命令、路径、截图文件名、表格行，两份不能有差异。
3. 不翻译的内容：代码块、配置键、CLI 命令、文件路径、`data-*` 属性、issue/PR 链接、persona 默认值（`蓝色大肥鱼`、`主人，再来一碗白米饭！！~` 是实际配置数据）、验证命令里的中文匹配串（`结构化输出（本会话已启用` 是注入文本原文）。
4. 不新增未实现的功能描述；两份同时改，不允许只改一份。

## 4. CHANGELOG 语言政策（2026-11-27 起）

1. **新条目中英双语，英文在前**：`## X.Y.Z` 版本标题下先写 `**English**` 段，再写 `**中文**` 段；同一版本的两段条目一一对应，版本号、数字、函数 / 字段名、`data-*`、路径与 issue / PR 编号两边一致，只翻译叙述文字。
2. **旧历史保持原样**：`1.3.1` 之前的条目（含 `1.3.0` 及更早）不翻译、不回填英文，也不重排或改写。
3. **只覆盖 `CHANGELOG.md`**：README 仍按第 3 节执行——英文默认、`README.zh.md` 完整中文镜像、两份顶部互跳；`docs/` 下的历史文档不翻译。

## 6. 设置页 i18n（未实现，仅计划）

现在没有实现，也没有排期。要做的话按这个顺序：

1. **抽文案**：把 `src/client.js` 里写死的中文标签、提示、空状态抽到语言包；建议沿用 `locale/<lang>.json`，按 `settings.*` / `persona.*` / `visual.*` 分组，避免和现有的 `meta.*` 混用。
2. **选语言**：默认跟随宿主语言，允许显式覆盖；落点仍是 profile Config（新增字段需要 schema 与设置页控件，不能只改前端）。
3. **注入提示词是否翻译要单独决策**：`src/index.js` 的注入文本影响输出形状与模型行为，翻译后必须按 `docs/METRICS.md` 的口径重跑 A/B，不能只换措辞。
4. **验收**：至少覆盖中英两种宿主语言下的设置页截图；两种语言的 key 集合必须一致，缺 key 回退英文。

## 7. 不做的

- 不翻译 `docs/` 下的历史文档与 `CHANGELOG.md` 的旧条目：它们是按时间记录的过程材料，翻译成本高、收益低；`CHANGELOG.md` 新条目按第 4 节做双语。
- 不做第三语言、不做文档站；中文版不是独立 fork，必须与英文版同步维护。
- 不在 README 里宣称尚未实现的 i18n 能力。

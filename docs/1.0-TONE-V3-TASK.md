# 2026-10-29 任务：语气风格页 v3 融合方案与原型

## 目标

把 zcode 的第三版融合方案落到一个可评审的 v3 原型上：

1. 先写一份可执行的 v3 计划。
2. 再做**一个** HTML 原型。
3. 不碰插件代码，不 commit / push；计划与原型经 Boss 确认后，才进入 DSH 落地。

## 已锁定的架构决策

- **位置**：DSH 插件设置内容区，真实内容宽度约 **960px**；宿主已提供插件头、tab、来源信息，原型不重画这些外壳。
- **版式**：**单列上下结构**。上方功能板块，下方预览板块；不做右侧常驻栏。
- **层级**：结构层（常开）→ 语气层（可选）→ 显示规则（固定）。
- **流程**：四步——选起点 / 调三句 / 看校样 / 保存。
- **字段**：`tone@2`，只允许 `schema / prefix / positive / suffix`；不做用户可编辑的 negative；排除场景为固定内置规则。
- **预览**：普通 / 表格 / 代码三态；表格隐藏落款，代码隐藏全部签名；复制不带签名。
- **状态**：已保存 / 未保存 / 未启用 / JSON 无效 / 保存中 / 只读；每个状态只住一个位置。
- **进阶**：JSON 折叠视图，不替换基础字段；允许恢复上次有效值。
- **视觉**：暖纸 + 锈色 + 石墨；只用一个强调色；标题/校样用中文衬线，标签/按钮用无衬线，键名/计数用等宽。
- **硬约束**：无“示例”字样、无破折号、无上传/下载/校验按钮、无 resize 控件、无 3D、无主题变体、无满屏胶囊/卡片套卡片。

## 验收

- 960 下无横向滚动；上功能 / 下预览，主路径从上到下不断。
- 字号有 5 级层级；控件高度统一；标签列对齐；按钮尺寸统一。
- 不出现禁用文案与禁用控件。
- 预览三态规则正确；复制不带签名。
- 状态不互相冒充；JSON 无效时保存禁用。
- 交付后先给 Boss 评审，不直接改插件代码。

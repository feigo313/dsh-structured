## 3. 三方向

每个方向 = 一套「配色家族 + 文字规格」，覆盖三类样式。均为单强调色蓝 #2563eb + 语义功能色。

### A · 靛蓝工作台（console-pro）— C 语言的完成态

- **配色家族**：pane 面板头成体系——结论 `#dbe7ff` 蓝头 + 2px 蓝左条；下一步 `#1e293b` 深石板头（白字）；
  风险 `#fdf3e2` 琥珀头；**表格蓝头 `#eef4ff` + 斑马 + 三色状态签（通过 / 观察 / 阻断）**；
  **代码深头 `#0b1220` + 蓝 300 标题字 + 深底 `#0f172a`**。
- **文字规格**：结论衬线 19 / 面板头 14 mono / 正文 13.5 / 步骤号 `[01]` mono 11 / 落款 `#` mono 12。
- **气质**：IDE 精密感，和代码块 / 表格视觉最连续；下一步深头是本轮对未决项的新提案，需拍板。
- 文件：`tone-v5-a-indigo.html`（截图 `tone-v5-a-*.png`）

### B · 蓝图制图（blueprint）— 制图图纸语言

- **配色家族**：蓝图蓝做骨架色（线框 / kicker / 表头 / 步骤号），琥珀警示；预览画布带 16px 淡蓝图网格，
  结构块四角有蓝色制图角标。
- **文字规格**：字级当主角——结论衬线 21（三方向最大）、kicker 小标 11 mono 宽字距（.22em）、
  正文 13.5、表格 2px 墨色报头规线 + 蓝表头、语气行楷体、落款右对齐像信末。
- **气质**：文化气 + 工程图纸感；「设计感」密度最高，依赖本机楷体（已验证可看）。
- 文件：`tone-v5-b-blueprint.html`（截图 `tone-v5-b-*.png`）

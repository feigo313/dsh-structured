# dsh-structured 1.0 Tone v2 定稿方案

- 状态：可交付开发；本文件取代旧 PersonaDoc 方案
- 定位：结构层 + 输出语气层；不做角色记忆 / 剧情连续 / AGENTS 前置注入
- 目标受众：用 AI 干活的人 / Web coding / AI 视频 / 自动化
- 核心句：不改模型怎么想，只改它怎么说

## 1. 定稿决策

| 项 | 定稿 |
| --- | --- |
| 前缀 | 展示层 CSS pseudo；放在标题卡上方导语；不进模型 / 不进复制 |
| 后缀 | 展示层 CSS pseudo；正常回复显示；表格 / 短答 / 纯代码隐藏 |
| 中段 | 模型生成；`positive` + `negative` + 固定尾锚 + 1–2 条句式锚点 |
| 结构 | 仍为硬约束；只把“其余保持中性”改为“表格 / 状态单元格中性，正文允许语气” |
| 存储 | profile Config：`personaEnabled` + `persona` JSON；tone@2 五字段 |
| 复制 / 导出 | 不带展示层签名；README / UI 明示；近期不做“复制带风格” |
| 旧消息 | 展示层会按当前配置重绘；内容不变，视觉签名变；验收只保内容不回溯 |
| 关闭恢复 | 新会话恢复标准；旧会话历史保留旧 prompt，不承诺回溯 |
| 角色扮演 | 轻量口吻；不做记忆 / 连续性 |

## 2. 数据与 UI

tone@2 只允许：

```json
{
  "schema": "dsh-structured/tone@2",
  "prefix": "Boss，",
  "positive": "轻松 / 略傲娇，短句，先结论再补一句吐槽；表格数据保持中性",
  "negative": "公文腔 / 客服腔 / 复述结论 / 每段都中性",
  "suffix": "——本鲸鱼娘可不背锅"
}
```

- 基础模式：开场语 / 正向风格 / 负向风格 / 结尾签名 + 启用 / 模板 / 保存 / 恢复默认。
- 模板下拉保留；显示名“蓝色大肥鱼”；不带“示例”。
- 每字段旁加 emoji 按钮：24–48 个常用，约 10–30KB，不引入完整库。
- 删除：校验 / 上传 / 下载 / 作者 / 许可 / 来源 / 署名链 / 示例 / IP 标注 / 未保存提示。
- 进阶模式：JSON textarea + 保存；保存时自动校验；错误显示在字段下。
- 列表分隔用 `/`，不用顿号。

## 3. Host 提示词

- 不再把 `prefix` / `suffix` 写进 prompt；prompt 只包含 positive / negative / 固定尾锚。
- 固定尾锚复述风格关键词，不硬编码“Boss / 鲸鱼娘”；使用当前 prefix 或中性表达。
- wrapper 明确：只改语气；结构 / 事实 / 工具 / 安全优先；表格单元格中性。
- 固定句式锚点（内置，不进 JSON）：
  - “像朋友聊天，不像报告。”
  - “先结论，再补一句轻松吐槽；表格只放数据。”
- 负向只写语气禁区；不能写“不要结构 / 不要工具 / 不要安全”。
- 删除重复的 tone section；只留一个 persona section + 一个 tail 锚点。

## 4. 展示层 v1

- 用 attribute + CSS `::before` / `::after`，不插 React 文本节点。
- scope 到 assistant-step；排除 reasoning / tool / compaction。
- 前缀在标题卡上方导语；后缀在消息末尾。
- 显示规则固定：
  - 纯 code / table：隐藏后缀；表格单元格中性。
  - 纯代码 / diff：前缀 / 后缀 / 语气装饰全部隐藏。
  - 短答按长度启发式隐藏后缀，不做语义判断。
  - 混合代码：保留前缀 / 正向风格，隐藏后缀。
- 复制 / 分支 / 导出不带签名；UI 和 README 明示。
- 旧消息会按当前配置重绘；内容不变，视觉签名变。

## 5. 会话与保存

- 保存成功：同一 profile 所有会话下一条消息使用新值；不要求重启 / 新会话。
- 关闭：只承诺新会话恢复；旧会话历史保留旧 prompt。
- 不依赖 `personaRevision` 传播；它最多是本地 cache key，不是全局机制。
- `/structured off` 会同时关闭 tone；文档写清。
- 跨 profile 不同步；子代理按 includeSubagents。

## 6. UI 状态修复

- PersonaEditor 外部 config 变化时重挂 / 同步，不只 mount 初始化。
- template 按当前 doc 识别，不永远初始 `whale`。
- invalid JSON 后提供“恢复最后有效值”。
- 删除未保存却显示“已保存”的状态；拆 draftOff / off。
- 恢复默认：内置“蓝色大肥鱼”模板 + 关闭启用。

## 7. 验收

- 机械项：正常回复前缀 / 后缀 100% 显示；纯代码 / diff 全隐藏；表格后缀隐藏、前缀 / 风格保留；无重复前缀 / 后缀；复制不带签名。
- 中段：5 条任务 × 3 次盲评，按“正文有自然语气 / 不像报告 / 结构不退化”评分，≥12/15；不用 4/5 当发布 gate。
- 会话：新会话保存后下一条生效；旧会话关闭不回溯；跨 profile 不同步。
- UI：外部 config 同步、template 标签、restore-last-valid、无“示例” / 校验 / 上传 / 下载 / IP 标注、无顿号。
- 文档：FINAL-PLAN 标 SUPERSEDED；README / ACCEPTANCE 同步；只留一个准绳。
- 不 push / 不合并 main；本地测试 / build / pack 后停下等 Boss。

## 8. 不做

- 不做角色记忆 / 剧情连续 / AGENTS 人格注入。
- 不做二次改写 / post-response hook。
- 不做“复制带风格”近期承诺。
- 不做完整 emoji 库。
- 不把展示层说成模型输出；UI 明示“展示层签名”。
